# GameForge3D

GameForge3D is an AI-powered web platform that takes a text prompt and produces (a) a game-engine-ready asset package at 4 LOD levels and (b) a fabrication-validated 3D-printable STL, using three self-trained models (DistilBERT-based Asset Category Router, Shap-E-style 3D Shape Generator, U-Net Texture Generator) with no external APIs or pretrained weights.

## Modules
* Asset Category Router
* 3D Shape Generator
* Texture Generator
* LOD Generation
* STL Fabrication Validation
* Export & Packaging
* Web App (FastAPI + React + Three.js)

## Tech Stack
PyTorch, HuggingFace Transformers/Diffusers, Open3D, PyMeshLab, trimesh, CuraEngine, reportlab, qrcode, FastAPI, React+TypeScript, Three.js, Render, Vercel, Supabase.
